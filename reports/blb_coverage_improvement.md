# Replay coverage: unidentified public hand losses

Same 5,000-game Bloomburrow Premier Draft prefix sample as earlier experiments.
Source: 17Lands public datasets, CC BY 4.0. The source checksums, exact settings,
stop examples (evaluation-only), and all twelve audit comparisons are in
[blb_coverage_improvement.json](blb_coverage_improvement.json).

This change expands usable turn summaries before introducing a more complex
predictive model. It leaves earlier strict experiments unchanged by default.

## Mechanism

The previous parser stopped whenever the end-of-turn hand differed from the
hand reconstructed using ordinary draws and named departures. Many missing
movements occur during the other player's turn. The public hand size can show
a loss even when no target-card identity is recorded.

With `allow_unknown_departures=True`, the parser calculates a **net loss count**
from public sizes, anonymous recorded draw counts, and public named departures.
It does not resolve the lost card's identity or infer the action that caused
it. The independent label audit accepts this step only when the actual hand
is a subset of the accounted hand with exactly that many cards missing. An
unexplained gain or replacement is still rejected, including a replacement
that happens to produce a net loss. A count-consistent public history alone
is not an audited training example.

The baseline marginalizes these identities as random departures, using the
same exchangeability assumption as its existing random-play model. Unknown
losses remain part of the latent unseen card pool when calculating marginal
hand probabilities; their counts are tracked for deck-exhaustion feasibility.
An exhaustive physical-card enumeration unit test checks this calculation.

## Reconstruction results

Both columns use the same games, include the existing opt-in kept-mulligan-hand
support, and scan all 30 rounds represented by the CSV schema. There are
84,787 available recorded half-turn states in this sample. No private card
identities are added to public inputs.

| Measure | Strict audit | Unidentified losses enabled |
| --- | ---: | ---: |
| Accepted hand snapshots | 57,810 | 64,182 |
| Fraction of recorded snapshots accepted | 68.2% | 75.7% |
| Games with at least one accepted snapshot | 4,973 | 4,999 |
| Games reaching every recorded state | 2,037 | 2,636 |

That is **6,372 additional snapshots (+11.0%)** and **599 additional fully
tracked games (+29.4%)**. Without mulligan support, accepted snapshots increase
from 49,547 to 55,045 and fully tracked games from 1,729 to 2,241.

The first-three-round window also improves: with mulligan support, accepted
states increase from 28,548 to 29,232 (95.2% to 97.5% of recorded early states).
Games with no stop inside a short window are not counted as complete unless
all of their available recorded states were reached.

## Remaining gaps and interpretation

With unidentified losses and mulligans enabled, full-window stops are:

- 1,407 games with unexplained hand movements, including off-turn gains,
  returns, and card replacements.
- 710 games with a named departure absent from the reconstructed hand.
- 246 games encountering recorded tutors/selections.
- One inconsistent opening-hand size.

These are first-stop counts. Fixing an earlier stop can expose a later failure,
so some categories increase even as total coverage improves. Matching card-type
counts does not prove casting zone provenance or rule out hidden offsetting
movements. The new counts describe net changes, not a complete action log.

These are **reconstruction coverage gains**, not accuracy gains. The finite
historical-deck prior can still reject otherwise audited histories. Full-game
prediction performance is reported separately; it must not be compared directly
to earlier early-turn scores as if the evaluation population were unchanged.
The site’s existing exported examples have not been regenerated by this audit.

## End-to-end inference check

The expanded experiment scans up to round 30 on the same held-out split:
205 events / 971 games, with 4,180 prior deck configurations and zero event
overlap. Mulligan-hand support and unidentified departures are both enabled.
See [blb_hands_expanded_coverage.json](blb_hands_expanded_coverage.json).

Of 12,448 audited held-out snapshots, **8,644** receive predictions. The other
**3,804** are excluded because no prior deck is compatible. All 971 held-out
games have at least one evaluable snapshot; that does not mean predictions
reach every game's ending.

| Metric | Public movements | Hand size only |
| --- | ---: | ---: |
| Recall@5 | 0.2678 | 0.2259 |
| Recall@10 | 0.3621 | 0.2660 |
| Recall@20 | 0.4896 | 0.3649 |
| MRR | 0.6021 | 0.4472 |
| Brier (lower is better) | 0.01461 | 0.01528 |

These are paired comparisons on the same accepted snapshots, averaged within
games and then across games. The 95% event-bootstrap interval for the top-20
recall improvement is 11.0–14.1 percentage points. This verifies that the
expanded pipeline runs and compares against its baseline. It does **not**
estimate an accuracy improvement caused by the parser change: earlier reports
cover different turns and a different population.

Tests cover private-identity invariance, mixed gains/losses, library exhaustion,
exact random-departure marginalization, and recorded-ending coverage. A scan
of all 5,000 games also confirmed that the strict accepted prefix of every
game is unchanged and matches the expanded public adapter up to each accepted
label. No existing site examples or aggregate benchmark files were overwritten.
